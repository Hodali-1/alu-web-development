# HTML advanced - SmileSchool

![Holberton School logo](https://www.holbertonschool.com/holberton-logo.png)

## Description
In this project I build the **SmileSchool** landing page from a Figma designer file.
This first part focuses only on the **HTML structure**: no CSS, no style, just pure semantic HTML.

## Page structure
| Section | Content |
|---------|---------|
| Header | Clickable logo and 3 links (Courses, Pricing, Login) |
| Banner | Title, subtitle, register button and 4 "pros" profiles |
| Quote | Profile picture, quote, author and job title |
| Videos | "Most popular tutorials": 4 video cards with author and 5-star rating |
| Membership | "Free membership": 4 items and a register button |
| FAQ | 2 rows of 2 questions with answers |
| Footer | Logo, social media links and copyright |

## Learning objectives
- What is HTML and what is a markup language
- How to create an HTML page from a wireframe
- What is the DOM
- What is an element / tag and what is an attribute
- The purpose of each HTML tag

## Requirements
- All files end with a new line
- Only HTML/CSS/JavaScript, no external libraries
- Code is W3C compliant
